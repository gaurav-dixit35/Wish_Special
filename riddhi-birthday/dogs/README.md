Ten transparent dog stickers are installed as `dog-01.png` through `dog-10.png`.

Each is a 400 × 400 PNG with transparent padding. The existing dog guide rotates
through these files across chapters and the finale parade. CSS placeholders
remain as a fallback if a file fails to load.

See [SOURCES.md](SOURCES.md) for the public-domain/CC0 source pages, original PNG
URLs, and preparation notes.
